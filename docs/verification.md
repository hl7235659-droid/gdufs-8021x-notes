# 证据与可信度分级

本文件回答一个具体问题：**上面那些结论，各自被验证到了什么程度？**
凡只有单一来源、或尚未复核的，都在这里点名。

## A 级 · 官方客户端锚点（3 组）

来自本校区**官方 Windows 客户端**成功会话的抓包，可用于判断实现是否正确：

| 向量 | 挑战 | 变体 | 说明 |
| --- | --- | --- | --- |
| `official V6.86 · variant 4` | `0538a637…c2af2a` | 4 | 与本地实现 128 字符逐位相同 |
| `official V6.86 · variant 2` | `e715920d…e532c9` | 2 | 同一份抓包的另一轮 |
| `official retry · variant 0` | `761bca12…e0c6ed` | 0 | **关键**：variant 0 有官方成功帧——这直接排除了"variant 0 被服务器禁用"的旧猜测 |

三点说明：

1. 第三组正是历史上本地实现失败的那个变体；修好之后与官方逐字符相同。
2. 这 3 组的复现需要**你自备同代客户端**（见 `tables.md`）：摘要的输入包含客户端镜像。
3. `vectors/vectors.json` 里另有 1 组"真机第三方客户端成功会话"的向量（服务器已接受该摘要），它证明**服务器会放行该实现**，但不等于"与官方逐字符相同"——两类证据不要混为一谈。

## B 级 · 可复现构建与产物身份

| 断言 | 值 | 意义 |
| --- | --- | --- |
| 部署二进制 | 221,304 字节，SHA-256 `1f4a7454…355bb881` | 真机在跑的那一份 |
| 对应安装包 | SHA-256 `5d47a42a…e019334`；解包后内层 `usr/sbin/minieap` 与上面同哈希 | 包与二进制身份绑定 |
| **陷阱** | 未打补丁的同名同版本包内层是 `5afe2a23…` | **同名同版本 ≠ 同一个二进制**；校验必须按内容哈希，不能按版本号 |
| 离线重建 | 用同一 SDK/缓存重建，整包哈希一致 | "能重来一次"这条成立 |

## C 级 · 帧级 golden（2 个真机成功样本）

对两个成功会话做结构性回归（本仓库**不分发抓包**，只描述断言口径）：

- 帧序列：EAPOL-Start → Req/Identity → Resp/Identity → 两轮 Req/Resp-MD5 → EAP-Success；
- 每帧 `EAPOL length == EAP length`；填充只出现在 60 字节短帧；
- Identity 应答**不含**私有段（历史缺陷回归项）；
- MD5 应答：值长度 16、客户端标识属性 `(0x11, 36)`、私有段长度自洽、**两轮仅摘要区 16 字节不同**；
- 两轮挑战相同；第二轮请求携带约 200 字节的服务端私有段（17 个 TLV）；
- 变体分派：抓包挑战 → `win_v3_variant` 分类与日志记录一致。

两个样本分别覆盖：**裸格式 + variant 0（412 长度）** 与 **含 IPv6 属性 + variant 3（485 长度）**。

## D 级 · 合成向量（3 组）

| 向量 | 变体 | 性质 |
| --- | --- | --- |
| `synthetic const · variant 0` | 0 | 常量输入（客户端内出现的一个字符串），无官方会话 |
| `synthetic · variant 1` | 1 | 无官方成功帧可对照（另一代客户端的挑战），仅内部自洽 |
| `synthetic · variant 3` | 3 | 人为构造（把 variant 2 的挑战第 5 字节 `c9→ca` 以落进 variant 3） |

它们的作用是**防回归**与"覆盖 5 个变体"，**不能**当作"与官方一致"的证据。

## 单一来源 / 未复核项（请当成待办）

1. **表数据的生成过程缺失**：能确认"某一版客户端里表长什么样、怎么被调用"，但拿不到"这些表最初是如何被推导出来的"完整链条（`tables.md` §3）。
2. **变体 1、3 无官方锚点**（只有合成向量）。
3. **两条取模链的关系**（`0x570340` vs `Vz_API`）未确认。
4. **服务器判定范围**：`0x53` 是整体判决，材料不足以断言"只由 `0x4d` 决定"；`0x2f` 或会话状态是否参与，未知。
5. **那 8 字节块密码**的算法未复刻（只有确定性的输入/输出对）。
6. **楼栋差异**：本地结论只在两个样本所在接入点上验证过；其他楼栋请自行实测并回报。
